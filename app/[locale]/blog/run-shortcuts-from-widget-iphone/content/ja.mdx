# iPhoneのウィジェットからショートカットをワンタップで実行する方法（iOS 27）

**結論：** iOS 27では、ウィジェットからショートカットやAppのアクションを、ショートカットAppを開かずに実行できます。[WidgetLoft](/widgetloft)でグループウィジェットを長押しし、**ウィジェットを編集**をタップして**アクション**を開き、自作のショートカット、Appのアクション（「タイマーを設定」など）、アプリを追加しましょう。アプリのタイルの隣に並び、ワンタップで実行されます。ボタンだけのウィジェットが欲しいなら、**アクションボード**をホーム画面かロック画面に追加します。

これまでのショートカットウィジェットも役目は果たしていましたが、見た目はいつもショートカットAppそのものでした。これからは、毎日開くアプリと同じグリッドにショートカットを置けます。

---

## iOS 27で変わったこと

iOS 27では、アプリが自分のウィジェットにショートカットやAppのアクションを置き、タップで実行できるようになりました。以前は、サードパーティ製ウィジェットでショートカットをタップすると、たいていまずショートカットAppが開き、それから実行されていました。

これがいちばん効くのは、ちょっとした繰り返しの作業です。タイマーを始める、集中モードをオンにする、水を1杯飲んだと記録する、「今向かってます」とメッセージを送る。ワンタップで、アプリを切り替える必要もありません。

ショートカットをたくさん自作する方には、iOS 27で、やりたいことを普通の言葉で説明して作る新しい方法も加わりました。Appleによると一部のショートカット機能は今後のアップデートで提供されるため、**ショートカット → +** に何が表示されるか確認してみてください。

## 手順：ランチャーウィジェットにアクションを追加する

1. **iOS 27にアップデートする。** **設定 → 一般 → ソフトウェアアップデート**を開きます。ウィジェット内のアクションは古いバージョンにはありません。
2. **「ウィジェットを編集」を開く。** WidgetLoftのグループウィジェットを長押しして**ウィジェットを編集**をタップし、**アクション**を開きます。
3. **実行したいものを追加する。** 自作のショートカット、Appのアクション、アプリを選びます。グループ本来のタイルの後ろにタイルとして表示されます。
4. **アクションを好きな位置に移す。** [WidgetLoft](/widgetloft)でグループを開き、稲妻ボタン（**ウィジェットアクションを追加**）をタップします。アクションを選び、そのタイルを好きな位置へドラッグします。2つのアプリの間にも置けます。
5. **アイコンを付ける。** iOSはアクションにアイコンを用意しないため、WidgetLoftが探します。アクションとまったく同じ名前のアプリがあれば、そのアイコンが使われます。なければ候補が表示されるので選ぶか、自分で作れます。

ホーム画面でタイルをタップすればアクションが実行されます。ウィジェットはそのままの状態を保ちます。

## アクションボードを作る

ボタンだけのウィジェットが欲しいときもあります。それが**アクションボード**です。

1. ホーム画面の何もない場所を長押しし、**編集**、続いて**ウィジェットを追加**をタップします。
2. WidgetLoftを探し、**アクションボード**（通常またはLiquid Glass）を好きなサイズで追加します。
3. 追加したボードは最初は空です。長押しして**ウィジェットを編集**をタップし、**スタイル**でボードを選んでアクションを追加します。
4. ボードの見た目を変えたり、アクションにアイコンを付けたりするには、WidgetLoftで**ツール → アクションボード**を開きます。

1つのボードに最大64個のアクションを置けます。ロック画面では2つの形を選べます。Large（1列または2列）とSmall（アクション1つ、または2×2のグリッド）です。これでロック画面が本格的なコントロールパネルになります。iPhoneのロックを解除してショートカットを探さなくても、「退勤」ショートカットをワンタップで実行できます。

## ショートカットウィジェットとWidgetLoftのアクションの比較

| | Appleのショートカットウィジェット | WidgetLoftのアクション（iOS 27） |
| --- | --- | --- |
| ショートカットとアプリタイルを混在 | 不可 | 可能、同じグリッドに |
| Appのアクション（「タイマーを設定」など） | 不可 | 可能 |
| ロック画面 | ウィジェットとしては不可 | アクションボード、LargeまたはSmall |
| カスタムアイコン | ショートカットのグリフ | アプリのアイコン、または自作のアイコン |

タップしなくても自動で動くショートカットも使いたい方は、[ホーム画面で使うiOS 27のショートカットのオートメーション](/blog/ios-27-shortcuts-automations-home-screen)もご覧ください。

## よくある質問

**アクションをタップするとショートカットAppが開きますか？**
いいえ。iOS 27ではアクションがウィジェットから直接実行され、ウィジェットはそのままの状態を保ちます。

**iOS 26以前でも使えますか？**
いいえ。ウィジェット内のアクションとAction BoardにはiOS 27が必要です。WidgetLoftの通常のアプリタイルはiOS 18以降で動作します。

**アクションボードにはアクションをいくつ置けますか？**
最大64個です。一度に表示される数は、追加したウィジェットのサイズによって変わります。
