# 아이폰 위젯에서 하위 폴더마다 다른 모양 주는 방법

**빠른 답변:** Apple의 홈 화면 폴더는 모두 똑같이 생겼습니다. [WidgetLoft](/widgetloft) 위젯에서는 이제 하위 폴더마다 자기만의 스타일을 가질 수 있습니다. 하위 폴더를 열고 **모양**을 탭해 그 폴더만의 아이콘 크기, 앱 이름, 간격, 색상을 설정하세요. 폴더 타일에 사진이나 심볼을 지정하고, 뒤로 버튼을 다시 꾸미고, 폴더가 열리는 방식도 고를 수 있습니다.

크고 화려한 아이콘의 "게임" 폴더와 작고 차분한 아이콘의 "업무" 폴더는 한눈에 구분하기 쉽습니다. 이제 위젯 하나에 둘 다 담을 수 있습니다.

---

## 하위 폴더마다 다른 모양을 주는 이유

하위 폴더를 쓰면 위젯 하나에 칸 수보다 훨씬 많은 앱을 담을 수 있습니다. 폴더 하나에 앱 100개와 하위 폴더 20개까지 넣을 수 있고, 중첩 깊이에는 제한이 없습니다. 위젯에서 폴더를 탭하면 그 자리에서 열립니다.

문제는 모든 단계가 똑같이 생겼다는 점이었습니다. 앱이 6개인 폴더도 40개인 폴더와 똑같이 작은 아이콘을 썼죠. 하위 폴더마다 모양을 정할 수 있으면, 앱이 적은 폴더는 큰 아이콘을, 앱이 많은 폴더는 작은 아이콘을 써서 한 화면에 모두 담을 수 있습니다.

## 단계별 안내: 하위 폴더 꾸미기

1. **하위 폴더를 여세요.** WidgetLoft에서 그룹을 연 다음 바꾸고 싶은 하위 폴더를 엽니다.
2. **모양을 탭하세요.** 이 하위 폴더만의 **아이콘 크기**, **앱 이름**(켬 또는 끔), **간격**, **색상**을 설정합니다. 그룹의 나머지 부분은 그대로입니다.
3. **폴더 타일을 고르세요.** 바깥에서 폴더가 어떻게 보일지 고릅니다. 안에 든 앱의 2×2 또는 3×3 미니 그리드, 직접 고른 사진, 또는 SF Symbol 중에서 선택합니다.
4. **뒤로 버튼을 꾸미세요.** 심볼, 색상, 배경, 불투명도, 크기를 고르고 원하는 칸으로 드래그합니다. **이 모양 적용 대상**에서 이 폴더, 이 그룹, 또는 모든 그룹에 적용하고, 새 하위 폴더도 이 모양으로 시작할지 정합니다.
5. **애니메이션을 고르세요.** WidgetLoft **설정**에서 **하위 폴더 전환**을 슬라이드, 페이드, 확대/축소, 즉시 중 하나로 설정합니다. 즉시가 가장 빠릅니다.

## 무엇을 어디서 바꿀 수 있나

| 설정 | 위치 | 적용 범위 |
| --- | --- | --- |
| 아이콘 크기, 이름, 간격, 색상 | 하위 폴더 → 모양 | 해당 하위 폴더 |
| 폴더 타일 (미니 그리드, 사진, 심볼) | 하위 폴더 설정 | 바깥에서 보이는 모양 |
| 뒤로 버튼 | 하위 폴더 → 뒤로 버튼 | 폴더, 그룹 또는 모든 그룹 |
| 열기 애니메이션 | 설정 → 하위 폴더 전환 | 모든 위젯 |

나중에 다시 정리해야 하나요? 하위 폴더를 다른 그룹으로 옮기거나 복사할 수 있고, 안에 든 모든 것이 함께 따라갑니다. 중첩 폴더가 처음이라면 [아이폰에서 폴더 안에 폴더 넣는 방법](/blog/folders-inside-folders-iphone)부터 시작하세요.

## 폴더의 알림 점

iOS 27에서는 폴더 안의 앱에 알림 점이 있으면 폴더에도 점이 표시되므로, 두 단계 깊이 숨어 있는 메시지도 놓치지 않습니다. 기본적으로는 도착한 알림 개수가 표시되며, 점만 표시하려면 **설정 → 알림 점 → 숫자 표시**를 끄세요. 전체 설정 방법은 [위젯 알림 배지](/blog/notification-badges-on-widgets-iphone)에서 확인하세요.

## 자주 묻는 질문

**아이폰에서 폴더 안의 폴더를 서로 다르게 꾸밀 수 있나요?**
Apple의 폴더로는 안 됩니다. WidgetLoft 위젯에서는 하위 폴더마다 아이콘 크기, 앱 이름, 간격, 색상을 따로 지정할 수 있습니다.

**하위 폴더는 몇 개까지 만들 수 있나요?**
폴더 하나에 앱 100개와 하위 폴더 20개까지, 깊이 제한은 없습니다.

**하위 폴더에도 알림 점이 표시되나요?**
네, iOS 27에서 가능합니다. 폴더 안의 앱에 점이 있으면 폴더에도 점이 표시되며, 기본적으로 알림 개수가 함께 표시됩니다.
